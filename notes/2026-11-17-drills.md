## 1. mux2 - 1-bit 2:1 multiplexer

| Signal | Width | Dir | Meaning |
|---|---|---|---|
| `s` | 1 | in | Select. `0` selects `a`, `1` selects `b` |
| `a` | 1 | in | Data input 0 |
| `b` | 1 | in | Data input 1 |
| `y` | 1 | out | Selected input |

- Written as one assign using a conditional operator **is allowed here** (this is the only drill where it is).
- Vectors: **8/8 exhaustive** (`s`, `a`, `b`).
- Success line: `ALL PASS (8/8)`.

## 2. mux4 - 1-bit 4:1 multiplexer, structural

| Signal | Width | Dir | Meaning |
|---|---|---|---|
| `s` | 2 | in | Select, `s[1]` is the high bit |
| `d` | 4 | in | `d[0]`..`d[3]` data inputs |
| `y` | 1 | out | `y = d[s]` |

- **Instantiate three `mux2`** (two for the data, one to pick between them). No `case`, no `?:`.
- Vectors: **64/64 exhaustive** (`s` 2 bits x `d` 4 bits).
- Success line: `ALL PASS (64/64)`.
- Check after: does the netlist have exactly 3 sub-modules? `iverilog -g2012 -o /dev/null -Wall rtl/*.v tb/tb_mux4.v` must be silent.

## 3. busmux4 - 8-bit wide 4:1 multiplexer, parameterized

| Signal | Width | Dir | Meaning |
|---|---|---|---|
| `s` | 2 | in | Select |
| `d0`,`d1`,`d2`,`d3` | `W` | in | Data inputs, `W` default 8 |
| `y` | `W` | out | `y = dN` where `N = s` |

- `parameter W = 8`. The module must work unchanged for `W = 4` and `W = 16` (instantiate a
  second instance in the testbench with `#(.W(16))` and check one vector through it).
- Vectors: **1024 checks.** For each `s`, sweep the selected input `0..255` while the other three
  hold distinct constants (`8'h00`, `8'hFF`, `8'h55`). Exhaustive over all four data inputs is
  2^34 and is not the point.
- Also check `s` from 2'b00 to 2'b11 with all inputs equal: `y` must equal that value.
- Success line: `ALL PASS (1024/1024)` (plus whatever the W=16 instance adds, if counted separately).

## 4. dec2_4 - 2:4 decoder with enable

| Signal | Width | Dir | Meaning |
|---|---|---|---|
| `en` | 1 | in | Enable. `0` forces all outputs low |
| `a` | 2 | in | Address |
| `y` | 4 | out | One-hot: `y[a] = en`, every other bit `0` |

- **No inferred latch.** Every output bit must be assigned on every path. If `make lint` says
  `LATCH`, the structure is wrong - fix it, do not silence it.
- Vectors: **8/8 exhaustive** (`en` x `a`).
- Success line: `ALL PASS (8/8)`.

## 5. dec3_8 - 3:8 decoder, structural

| Signal | Width | Dir | Meaning |
|---|---|---|---|
| `en` | 1 | in | Enable |
| `a` | 3 | in | Address |
| `y` | 8 | out | One-hot |

- **Instantiate two `dec2_4`**: `a[1:0]` goes to both; `a[2]` enables the low or the high half,
  combined with `en`. No `case`, no bit-shift operator.
- Vectors: **16/16 exhaustive** (`en` x `a`).
- Success line: `ALL PASS (16/16)`.

## 6. enc4_2 - 4:2 encoder with valid

| Signal | Width | Dir | Meaning |
|---|---|---|---|
| `d` | 4 | in | One-hot input (exactly one bit set in valid use) |
| `y` | 2 | out | Index of the set bit |
| `valid` | 1 | out | `1` when exactly one bit of `d` is set, else `0` |

- `valid = 0` when `d == 0` **or** more than one bit is set (that second case is the trap).
- When `valid = 0`, `y` must still be a defined value (`2'b00`) - do not leave it floating.
- Vectors: **16/16 exhaustive** (`d` 4 bits), which covers all one-hot, all-zero and multi-hot cases.
- Success line: `ALL PASS (16/16)`.

## 7. dec_bcd - 4:10 decoder with an error output

| Signal | Width | Dir | Meaning |
|---|---|---|---|
| `a` | 4 | in | BCD digit, `0`..`9` valid, `10`..`15` invalid |
| `y` | 10 | out | One-hot for `0`..`9` |
| `err` | 1 | out | `1` when `a > 9`, all `y` bits `0` |

- Written with `case` (or `casez` is not needed) **plus `default`**. The `default` branch is the
  whole point of this drill: `y = 10'b0; err = 1'b1;`.
- Vectors: **16/16 exhaustive**.
- Success line: `ALL PASS (16/16)`.
- If `make lint` reports `LATCH`, you forgot to drive `y`/`err` in one branch.
